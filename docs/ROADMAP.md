## 추가 기능 (2026-10-29)

사용자가 범위를 **각주, KaTeX 수식, Mermaid**로 정했다. 완료:

- **각주**: `[^1]`을 위첨자로 표시(커서가 있는 줄에서는 원문), 마우스를 올리면 정의 내용 말풍선, 정의 줄 `[^1]: ...` 스타일, 정의 없는 각주는 경고 표시. 여러 줄 정의는 첫 줄만 사용.
- **수식(KaTeX)**: 인라인 `$x$`, 같은 줄 `$$x$$`, 블록 `$$ ... $$`(`$$`+엔터 또는 `Cmd+Alt+B`로 생성), 화학식 `\ce{}`(mhchem). 커서가 안에 있으면 원문 + 입력 중 미리보기(오류 메시지 포함), 밖에 있으면 렌더 결과. 가격 `$5 ... $6`은 수식으로 보지 않음. 자동 번호 매기기는 하지 않음.
- **Mermaid**: ```` ```mermaid ```` 블록을 다이어그램으로 렌더(처음 필요할 때만 불러옴), 편집 중에는 코드 아래에 미리보기, 문법 오류 표시.

- **도움말(`F1`, 메뉴 도움말)**: 단축키·입력 규칙·표/이미지·수식/다이어그램/각주·설정을 탭으로 정리. 단축키는 코드와 어긋나지 않도록 테스트(`helpContent.test.ts`)가 확인한다.

- **확장 인라인 서식**: 밑줄(`<u>`, `Cmd+U`), 하이라이트(`==`, `Cmd+Shift+H`), 위첨자(`^x^`, `Cmd+Alt+=`), 아래첨자(`~x~`, `Cmd+Alt+-`). 첨자는 공백 없는 짧은 글자만 대상.
- **목록 개선**: 빈 항목(`- `, `1. `)을 입력 즉시 표시로 바꿈, 들여쓰기 고정 폭(1.9em), 줄 넘김 시 항목 글자에 맞춘 들여쓰기, 항목 간격 8px, 빈 항목에서 엔터로 내어쓰기/목록 종료.
- **목록 기호/정렬 보강**: 글머리 ● ○ ■ □ (CSS로 그림, 4단계 주기), 번호는 오른쪽 정렬로 글머리와 같은 글자 위치, 이미지 원문은 고정폭 글꼴+아이콘, 공백 경로는 `<경로>`로 삽입(퍼센트 인코딩 없음).
- **조판 보강**: 이미지 하나만 있는 줄은 가운데 정렬. 공백만 남은 들여쓰기 줄과 항목에 이어지는 글줄은 항목 글자 위치와 같은 폭의 고정 칸으로 그려 커서가 튀지 않음. 줄 바꿈(`Shift+Enter`)은 공백 두 개로 저장(`<br/>` 방식은 미적용).
- **요소 단위 서식 적용 규칙**: 서식은 문법이 완성될 때(닫는 기호, `# `·`> `·`- `·`* `·`1. `의 공백) 적용하고, 기호는 커서가 그 요소 안쪽에 있는 동안만 보임(맨 앞/뒤 제외, 한글 조합 중 기호가 남는 문제 때문에 끝 위치에서는 숨김. 굵게/기울임/코드/취소선/링크/이미지/각주/밑줄/하이라이트/첨자). 이전에는 커서가 있는 '줄' 전체의 기호가 보였음.
- **커서 위치 안정화**: 제목 바로 아래 줄의 여백을 내용 유무와 무관하게 일정하게 두어, 글자를 입력해도 줄/커서가 아래로 밀리지 않음.
- **Tab/Shift+Tab 수정**: 목록 밖에서 Tab이 포커스를 아래쪽 체크박스/표 칸으로 넘기던 문제 해결(체크박스는 Tab 대상에서 제외), 하위 항목 함께 이동, 번호 자동 다시 매기기, 첫 항목/과도한 들여쓰기 방지.
- **수식 원문 색**(LaTeX 명령·중괄호·환경 이름·주석), Mermaid 여백 확대, 간트 차트 '오늘' 선 숨김.
- **이름 변경**: Melleaf → Nib (문서, 창 제목, 이미지 프로토콜 `nib-file`, 임시 파일 이름).
- **새 문서 닫기 시트**: 경로 없는 새 문서를 닫을 때 OS 대화상자 대신 이름·형식(.md/.txt)·위치(문서/데스크탑/다운로드/홈 또는 직접 선택)를 정해 저장 / 삭제 / 취소. 렌더러는 main이 내준 폴더에만 저장할 수 있고, 같은 이름이 있으면 덮어쓰기를 확인한다.
- **코드 블록 보강**: 줄 맨 앞에 ```를 치는 순간 닫는 펜스를 함께 만들어 아래쪽 블록과 합쳐지지 않게 함, 언어 목록을 언어당 한 항목(이름·별칭 검색)으로 정리하고 vscode-icons(MIT) 아이콘 표시.
- **인용 경계**: 인용 바로 아래 빈 줄은 화면에서 숨기고 커서가 건너뜀, 인용 줄 기호를 Backspace로 지우면 빈 줄을 끼워 인용 밖으로 내보냄(lazy continuation 방지).

남은 후보(미착수, 우선순위 미정): HTML 주석 스타일, 링크 확장(제목 이동·로컬 파일·참조 링크), Front Matter, 이모지 자동완성.

선택 사항(이전 목록): 소스 모드, 아웃라인, 내보내기(HTML/PDF), 자동 저장/복구, 링크 입력 중 UX, 표 `Cmd+L/E`, 클립보드 이미지 붙여넣기.
